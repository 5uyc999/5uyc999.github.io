# Lams

الهدف الأساسي من الموقع:

إنشاء موقع قوي جدًا وموثوق ومهيأ بالكامل للإعلانات الممولة وSEO بحيث يجذب آلاف الزيارات ويحوّل الزوار إلى عملاء فعليين يتواصلون معنا مباشرة لطلب الخدمة.

## Marketing Attribution & CRM (2026-09-16)

The site now keeps first-touch and last-touch attribution for form leads and marketing interactions.
Captured fields include UTM parameters, `gclid`, `gbraid`, `wbraid`, landing page, referrer, session ID and a short `LMS-...` reference code.

Public tracked interactions:
- Phone button click (`phone_click`) — this is a click attempt, not proof that a call was completed.
- WhatsApp button click (`whatsapp_click`) — the pre-filled WhatsApp message receives the same `LMS-...` reference code.
- Get quote CTA click (`get_quote_click`).
- Successful form submission (`form_submit`).

Admin CRM lifecycle:
- `new`
- `qualified`
- `unqualified`
- `quoted`
- `won`
- `lost`

The admin can store quoted value, actual sale value, unqualified reason and follow-up notes. Manual leads can also be created for phone/WhatsApp customers who did not submit a website form.

### Required database migration before deploying this code

Apply:

`supabase/migrations/20260916093000_lead_attribution_crm.sql`

The website code inserts the new attribution columns, so the migration must be applied to the production Supabase project before the updated frontend is deployed.

### Google Ads attribution

Keep Google Ads auto-tagging enabled so `gclid` can be stored. A readable campaign fallback can also be added using a Google Ads Final URL suffix, for example:

`utm_source=google&utm_medium=cpc&utm_campaign=lams_search&utm_term={keyword}&utm_content={creative}`

Do not put a leading `?` in Final URL suffix.

### Marketing funnel report

`/admin/tracking` now includes a first-touch source funnel with Leads, Qualified Leads, Sales, Lead-to-Sale rate and registered Revenue. This report becomes meaningful only when the operator consistently updates lead status and sale value.

### Environment files

Local `.env` files are ignored by Git. Keep production/local values out of commits and use `.env.example` as the key-name template.
